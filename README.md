# Mistfall Hunter Tools

Local-only 07 frontend implementation for `mistfallhunter.co`.

- Stack: Next.js + TypeScript + Tailwind CSS + OpenNext Workers configuration.
- `npm run build` validates the production Next build.
- `npm run start` runs a local preview after build.
- Deployment scripts/config exist for the later authorized release only. This task does not authorize Cloudflare mutations, Git push, deployment, DNS, or publication.
